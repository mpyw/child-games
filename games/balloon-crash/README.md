# ふうせん パン！（`balloon-crash`）

テレビにカメラの映像を鏡のように映し、その上に風船を浮かべる。子どもが
手で触ると風船が割れる。曲が終わったら、割った風船を並べてお祝いする。

遊び全般の決まり（装置に触らない、無反応にしない、など）は
[`games/README.md`](../README.md) にある。ここはこの遊びに固有のことだけ書く。

> [!IMPORTANT]
> **映像は画面に出すだけで、保存も送信もしない。** 子どもが映るため。
> 撮るのはこの遊びの間だけで、終われば必ずカメラを休ませる（ランプが消える）。

## 進行

```
song 開始 ─→ ┌→ カメラの絵を1枚待つ（毎秒30枚くらい）
             │   動いた所を出す → 重なった風船を割る（効果音）
             │   風船を足す・浮かせる・抜けたら消す → 鏡と風船を映す
             └── song が鳴り終わるまで（約1分）
         ─→ fanfare（割った風船を並べる）
         ─→ もう1回？（home の側で訊く）
```

| 押したもの | 起きること |
| --- | --- |
| 戻る | 曲を止めて「もう1回」の画面へ。お祝いはしない |
| 画面を押す（マウス） | 押した所に一番近い風船を割る。風船より少し広めに当てる |
| 十字キー・決定 | 何も起きない。押し間違いで遊びを切らない |

**時間切れという失敗は無い。** 1回の長さは曲の長さで決まり、終わりは必ず
お祝いになる。2歳児は制限時間を理解できない。1つも割れなかったときも、
全色の風船を並べて同じように祝う。

## 割れ方

**手の形は見ない。前の絵との差だけを見る**（`motion.rs`）。2歳児はぱーで
触るとは限らず、グーでも腕でも頭でも来る。何で触っても割れるほうがいい。
モデルも要らないので、ラズパイでも軽い。

| 決めごと | 理由 |
| --- | --- |
| 絵を 80×45 の升目に分け、升目ごとの明るさの平均で比べる | 1画素ずつ比べると、カメラのざらつきで割れ続ける |
| 風船の中で `touch_ratio` 以上の升目が動いたら割る | 体が少し揺れたくらいでは割れない |
| 全体の半分より広く動いたら、その1枚は無かったことにする | 明かりが点いたり、カメラが露出を合わせ直したりすると全面が変わる |
| 最初の1枚は何も動いていないことにする | 比べる相手が無い |
| 動いた升目に小さな光を出す | 自分が触っていることが見える |

> [!NOTE]
> カメラの絵は `home` が左右を反転して渡す。子どもが右手を上げると、画面の右が動く。

## 風船の出し方

`field.rs`。時刻は外から受け取るので、出す・浮かぶ・割れるの順を決まった形で
テストできる。

風船は下から上がってきて、手の届く帯ではゆっくり漂い、抜けたら上へ
飛んでいく。1つの風船が画面にいるのは約11秒。

```
画面の上 ─────────────  ↑ 毎秒120画素。飛んでいく、と分かる速さ
         ┌─ 32% ────┐
         │ 手の届く帯 │  ↑ 毎秒58画素。約4.5秒かけて通る
         └─ 68% ────┘
画面の下 ─────────────  ↑ 毎秒170画素。約2秒で帯まで来る
  （ここから出る）
```

| 決めごと | 狙い |
| --- | --- |
| 帯の中ではゆっくりにする | 触る時間を取る。止めてしまうと風船らしくない |
| 速さの境目は 80 画素かけてなだらかに変える | 急に変わると、引っかかったように見える |
| 上から抜けた風船は黙って消し、下から次を出す | 飛んでいったことを失敗として見せない |
| 同時に出すのは `max_balloons` 個まで。0.7秒おきに1つずつ足す | いっぺんに出すと、どれを狙うかで迷う |
| 出す場所は、他の風船と重ならない横位置を選ぶ | |
| 割れたら 0.3秒で次を出す | 叩いても何も無い時間を作らない |
| 現れてから 0.4秒は割れない | 出てきた瞬間に、たまたまそこで動いていた体で割れると手応えが無い |
| 8秒割れなければ、大きくし（最大 1.35倍）、浮かぶ速さも半分にする | 失敗にせず、誘う側に倒す |
| 風船は半径 88 画素（キャンバス 1280×720） | 大きく取る。2歳児の手は狙った所に行かない |

> [!TIP]
> 手の届く帯（`field.rs` の `REACH`）は、実機で子どもを映して決め直すとよい。テレビの大きさと、
> カメラからの距離で変わる。

## 画面

| 場面 | 映すもの |
| --- | --- |
| 遊んでいる間 | 暗くした鏡の映像、動いた所の光、風船、弾けた跡 |
| お祝い | 割った風船を並べて揺らす。数字は出さない |
| 「もう1回」の後ろ | お祝いと同じ並び（`home` が暗くする） |

鏡は少し暗くして敷く（0.55倍）。明るいままだと風船が背景に紛れる。暗く
しすぎると自分が見えず、どこを触ればいいか分からない。

## 音

| 素材 | 長さ | 口 |
| --- | --- | --- |
| `song.wav` | 61秒 | 曲（`Player::begin`）。この長さで1回が終わる |
| `pop-1.wav` 〜 `pop-3.wav` | 0.45秒 | 効果音（`Player::effect`）。順に回す |
| `fanfare.wav` | 4.2秒 | 曲。お祝いの間 |

**割れた音は曲を止めずに重ねる。** 効果音の口は1本なので、同時に2つ割れても
1回だけ鳴る。続けて割ると前の音を置き換える。

素材はすべて `tools/make_sounds.py` が数式から合成したもの。録音も既存の素材も
使っていないので、権利の心配が無く、そのままコミットしてある。乱数の種を
固定してあるので、何度作っても同じものになる。

```sh
uv run --with numpy python3 games/balloon-crash/tools/make_sounds.py
```

| 素材 | 中身 |
| --- | --- |
| 曲 | 120BPM・ハ長調・30小節。序奏 → A → B → A → 終わり。木琴の旋律、ベース、和音、軽い打楽器。2回目の A から鉄琴が重なる |
| 割れた音 | パンと弾ける雑音、下がる音、小さな鈴。3通りで高さを変えてある |
| お祝い | ラッパのような「たたたたーん・たたーん」と、最後の和音 |

曲を差し替えれば、1回の長さも変わる。

## つまみ

`config.toml` の `[games.balloon_crash]`。値の意味と環境変数名はそちらに書いてある。

| キー | 既定 | |
| --- | --- | --- |
| `max_balloons` | 3 | 画面に同時に出す風船の数（1〜6） |
| `threshold` | 28 | 明るさがこれだけ変わったら「動いた」とみなす（1〜255） |
| `touch_ratio` | 0.2 | 風船の中で、これだけの割合が動いたら割る |

| 困りごと | 動かすもの |
| --- | --- |
| 触っても割れない | `touch_ratio` を下げる。暗い部屋なら `threshold` も下げる |
| 触っていないのに割れる | `threshold` を上げる |
| どれを狙うかで迷っている | `max_balloons` を下げる |

## カメラ無しで試す

`camera` feature を外して組むと、カメラは何も映らない絵を返す。風船は
マウスで押して割れる。

```sh
cargo run --no-default-features --features window -- --game balloon-crash
```

## コード

| ファイル | 中身 |

| `src/play.rs` | 進行。`kit::Game` の実装と、装置なしの進行のテスト |
| `src/motion.rs` | 前の絵との差から、動いた升目を出す |
| `src/field.rs` | 風船の出し方・浮かび方・割れ方 |
| `src/look.rs` | 映すもの。鏡、風船、弾けた跡、お祝い |

| `tools/make_sounds.py` | 素材を合成する |
| `assets/` | 素材（`make_sounds.py` の出力） |
