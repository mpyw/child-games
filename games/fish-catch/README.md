# おさかなキャッチ！（`fish-catch`）

テレビにカメラの映像を鏡のように映し、下半分を池にする。池には魚やフグ、
タコ、サメが泳いでいる。魚の所に手を入れるとつかめて、勢いよく振り上げると
釣れる（片手でよい）。振り上げが弱いと、スルッと逃げられる。曲が終わったら、
釣った数を出し、釣ったものを並べてお祝いする。

遊び全般の決まり（装置に触らない、無反応にしない、など）は
[`games/README.md`](../README.md) にある。ここはこの遊びに固有のことだけ書く。

> [!IMPORTANT]
> **映像は画面に出すだけで、保存も送信もしない。** 子どもが映るため。
> 撮るのはこの遊びの間だけで、終われば必ずカメラを休ませる（ランプが消える）。

## 進行

```
song 開始 ─→ ┌→ カメラの絵を1枚待つ（毎秒30枚くらい）
             │   動きの向きと速さを出す → 魚ごとに、つかんだか・振り上げたかを見る
             │   釣れた・逃げた・つかんだ音を鳴らす → 鏡と池と魚を映す
             └── song が鳴り終わるまで（約1分）
         ─→ fanfare（「5ひき つれたね！」と、釣った魚を並べる）
         ─→ もう1回？（home の側で訊く）
```

| 押したもの | 起きること |
| --- | --- |
| 戻る | 曲を止めて「もう1回」の画面へ。お祝いはしない |
| 画面を押す（マウス） | 押した所の魚をすぐ釣る。カメラが無いときに試す口 |
| 十字キー・決定 | 何も起きない。押し間違いで遊びを切らない |

**時間切れという失敗は無い。** 1回の長さは曲の長さで決まり、終わりは必ず
お祝いになる。1匹も釣れなかったときも、全種類を並べて同じように祝う。

## 魚の移り変わり

`pond.rs`。見えたもの（つかんだ割合、左右の上向きの速さ）と時刻を外から
受け取るので、絵を組まずに確かめられる。

```
泳ぐ ─手が入った─→ つかまれる ─強く振り上げた─→ 釣れる
 ↑ │                  │
 │ │                  ├─ 弱い / 振り上げない ─→ 逃げる
 └─┼──────────────────┴──────────────────────────────────┘
   └─ 12〜18秒つかまれない ─→ 出ていく（別の魚と入れ替わる）
```

**放っておかれた魚は入れ替わる。** 同じ魚が往復し続けるだけだと、見ていて飽きる。
出ていく時刻は魚ごとにずらし、同時に出ていくのは1匹までにしてある。重なると
池が空っぽに見える。

| 様子 | 見えるもの | 次へ |
| --- | --- | --- |
| 泳ぐ | 池を左右に泳ぎ、端で折り返す | 魚のまわりで動きが 0.15秒続いたら、つかまれる。12〜18秒つかまれなければ出ていく |
| 出ていく | 近いほうの端へ泳ぎ（泳ぐより少し速い）、画面の外へ抜けたら消える。釣った数には入らない。**同時に出ていくのは1匹まで** | 空いたぶんは別の魚が外から入ってくる。途中でつかめば普通に釣れる |
| つかまれる | 魚が小刻みに跳ね、まわりに光が出る。「ピチピチ」 | 振り上げを見る。5秒振り上げなければ逃げる |
| 釣れる | 水しぶきを上げて、弧を描いて右上のバケツへ飛ぶ。「ザバーン」と鈴 | 1秒で池から消える。1.2秒で次の魚が出る |
| 逃げる | 少し跳ねて水に戻り、近いほうの端へ慌てて泳ぐ。「ツルン」 | 1.5秒はつかめない |

> [!NOTE]
> **手が止まっても、すぐには離れたことにしない。** 見ているのは動きなので、
> 魚の上で手を止めると動きが消える。0.4秒までの途切れは続けて見る。

## 振り上げの見分け方

**手の形は見ない。動いた向きと速さだけを見る**（`vision::Flow`、つかむ・振り上げるの判定は `vision::Grip`）。絵を
160×90 の升目に分け、升目ごとに前の絵のどこから来たかを探す（ブロック
マッチング）。モデルは要らない。

| 決めごと | 理由 |
| --- | --- |
| 振り上げを見る範囲は、魚の左と右に分け、魚の上 320 画素まで伸ばす | 振り上げた手はすぐ魚の所から出ていく。魚の所だけ見ると速さを取り損ねる |
| 向きが分かった升目が6つ未満なら、振り上げは無かったことにする | 1つ2つの升目は、カメラのざらつきでも向きを持つ |
| 1枚あたり 80 画素まで、ずれを探す | 測れる速さの上限はカメラの枚数で決まる。ラズパイの V15AF は暗い部屋で毎秒13枚ほどに落ち、そのとき毎秒 1040 画素まで |
| 左右どちらかが `swing_speed` の 35% を超えたら、振り上げを見始める | 振り上げの始まりを捉える |
| **左右どちらかが** `swing_speed` を超えたら釣れる | 片手でよい。両手を求めると、2歳児には厳しすぎた |
| 見始めてから 0.35秒で届かなければ逃げる | 弱い振り上げ |

### 逃げるたびに釣れやすくなる

逃げること自体は反応なので「無反応にしない」には合っている。ただ、続けて
逃げると2歳児は嫌になって離れる。逃げるたびに、釣れるのに要る速さを 85% に
下げる（最低で `swing_speed` の 50%）。釣れたら元の速さに戻る。

| 続けて逃げた数 | 0 | 1 | 2 | 3 | 4 | 5 以上 |
| --- | --- | --- | --- | --- | --- | --- |
| 要る速さ | 100% | 85% | 72% | 61% | 52% | 50% |

> [!NOTE]
> **体ごと跳ねても釣れる。** 上へ動いたことには変わりないので、見分けがつかない。
> 2歳児なら釣れてかまわないので、そのままにしてある。

## 画面

| 場面 | 映すもの |
| --- | --- |
| 遊んでいる間 | 鏡の映像（上は暗く、下半分は青く染めて池）、水面の波、魚、右上のバケツ |
| お祝い | 上に「5ひき つれたね！」と釣った数、下に釣ったものを並べて揺らす |
| 「もう1回」の後ろ | お祝いと同じ並び（`home` が暗くする） |

池は鏡の絵を半分ずつ混ぜて青くしてある。透けて自分の手が見えるので、
どこを触ればいいか分かる。

### 池にいるもの

| 種類 | 形 | 出る割合 |
| --- | --- | --- |
| さかな | 角丸の体、三角の尾と背びれ。色は6通り | 55% |
| フグ | まんまるの体に小さなトゲ、大きな目、おちょぼ口 | 18% |
| タコ | 丸い頭に、ゆらゆらする足4本、目2つ | 15% |
| サメ | 長い灰色の体に尖った鼻、白いお腹、三角の高い背びれ、二股の尾 | 12% |

**つかめる範囲は種類によらず同じ**（体の幅 230・高さ 110 画素の枠）。見た目だけが
違う。どの種類もこの枠の 1.6 倍に収まるように描いてある（テストで見ている）。
見た目だけ大きいと、触ったのに逃げたように見える。

お祝いの並びとバケツにも、釣った種類の形で出す。1匹も釣れなかったときは、
全種類を並べる。

## 音

| 素材 | 長さ | 口 |
| --- | --- | --- |
| `song.wav` | 61秒 | 曲。この長さで1回が終わる |
| `grab.wav` | 0.4秒 | 効果音。つかんだ |
| `catch.wav` | 1.4秒 | 効果音。釣れた |
| `slip.wav` | 0.6秒 | 効果音。逃げた |
| `fanfare.wav` | 4.4秒 | 曲。お祝いの間 |

効果音の口は1本なので、同じ1枚で2つ起きたら、釣れた > 逃げた > つかんだ の
順で1つだけ鳴らす。

素材はすべて `tools/make_sounds.py` が数式から合成したもの。録音も既存の素材も
使っていないので、そのままコミットしてある。乱数の種を固定してあるので、
何度作っても同じものになる。

```sh
uv run --with numpy python3 games/fish-catch/tools/make_sounds.py
```

| 素材 | 中身 |
| --- | --- |
| 曲 | 100BPM・ヘ長調・25小節。序奏 → A → B → A。木琴の旋律、揺れるビブラフォンの和音、ベース、ときどき泡の音。B からシェイカーが入る |
| つかんだ | 高い音が3つ、ピチピチと震える |
| 釣れた | 水しぶきの雑音と低いドボン、上がっていく鈴 |
| 逃げた | 滑り落ちる高さの音と、小さな水音 |
| お祝い | ラッパのような「たらららったーん」と、最後の和音 |

## つまみ

`config.toml` の `[games.fish_catch]`。値の意味と環境変数名はそちらに書いてある。

| キー | 既定 | |
| --- | --- | --- |
| `max_fish` | 3 | 池に同時に泳がせる魚の数（1〜4） |
| `threshold` | 24 | 明るさがこれだけ変わったら「動いた」とみなす（1〜255） |
| `grab_ratio` | 0.05 | 魚のまわりで、これだけの割合が動いたら「つかんだ」とみなす |
| `swing_speed` | 420 | 釣れる振り上げの速さ（毎秒の画素、50〜1000） |
| `show_motion` | false | 動きの向きと、振り上げの強さの棒を画面に出す |

> [!TIP]
> **しきい値は `show_motion = true` で見ながら決める。** 上へ動いた所は緑、
> 下へ動いた所は赤の点になる。つかんだ魚の左右に振り上げの強さの棒が出て、
> 白い線まで伸びれば足りている。
>
> ```sh
> DONNA_IRO_GAMES__FISH_CATCH__SHOW_MOTION=true ./donna-iro --game fish-catch
> ```

| 困りごと | 動かすもの |
| --- | --- |
| 手を入れてもつかめない | `grab_ratio` を下げる。暗い部屋なら `threshold` も下げる |
| 触っていないのにつかむ | `threshold` を上げる |
| 振り上げても釣れない | `swing_speed` を下げる |
| 簡単すぎる | `swing_speed` を上げる |

## コード

| ファイル | 中身 |
| --- | --- |
| `src/play.rs` | 進行。`kit::Game` の実装と、カメラの絵から判定までを通すテスト |
| `src/pond.rs` | 魚の種類と出し方、泳ぐ・つかまれる・釣れる・逃げる・出ていくの移り変わり |
| `src/look.rs` | 映すもの。池、4種類の形、水しぶき、バケツ、お祝い、調整用の表示 |
| `src/cue.rs` | 鳴らす素材。文字列ではなく型で指す |
| `src/config.rs` | `[games.fish_catch]` の型と検査 |
| `tools/make_sounds.py` | 素材を合成する |
| `assets/` | 素材（`make_sounds.py` の出力） |

動きの向きと速さ、つかんで振り上げたかを出すのは、共有クレートの `vision`
（`vision/src/flow.rs`、`vision/src/lift.rs`）。
