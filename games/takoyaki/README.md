# たこやき くるりん！（`takoyaki`）

テレビにカメラの映像を鏡のように映し、下に6つ穴のたこ焼き器を置く。生地が
焼けたら指でつついて裏返し、反対側も焼けたら、つかんで勢いよく振り上げると
右上の舟皿へ飛んでいく。空いた穴には次の生地が入る。曲が終わったら、焼けた
数を出し、ソースのかかったたこ焼きを並べてお祝いする。

遊び全般の決まり（装置に触らない、無反応にしない、など）は
[`games/README.md`](../README.md) にある。ここはこの遊びに固有のことだけ書く。

> [!IMPORTANT]
> **映像は画面に出すだけで、保存も送信もしない。** 子どもが映るため。
> 撮るのはこの遊びの間だけで、終われば必ずカメラを休ませる（ランプが消える）。

## 進行

```
song 開始 ─→ ┌→ カメラの絵を1枚待つ（毎秒30枚くらい）
             │   動きの向きと速さを出す → 穴ごとに、つついたか・つかんで振り上げたかを見る
             │   流した・裏返した・乗った音などを鳴らす → 鏡と鉄板とたこ焼きを映す
             └── song が鳴り終わるまで（約1分）
         ─→ fanfare（「12こ やけたね！」と、ソースのかかったたこ焼きを並べる）
         ─→ もう1回？（home の側で訊く）
```

| 押したもの | 起きること |
| --- | --- |
| 戻る | 曲を止めて「もう1回」の画面へ。お祝いはしない |
| 画面を押す（マウス） | 押した穴を進める。焼けていれば裏返す・舟皿へ飛ばす、焼けていく途中なら揺らす。カメラが無いときに試す口 |
| 十字キー・決定 | 何も起きない。押し間違いで遊びを切らない |

## 1つの穴の移り変わり

`plate.rs`。見えたもの（穴の中で動いた割合、左右の上向きの速さ）と時刻を外から
受け取るので、絵を組まずに確かめられる。

```
空 ─→ 生地を流す ─→ 片面が焼けていく ─→ 焼けた ─つつく→ 裏返る
 ↑                     （つついても揺れるだけ）              ↓
 │                                               反対側が焼けていく
 │                                                         ↓
 └── 舟皿へ飛ぶ ←─強く振り上げた─ つかむ ←───────────── 焼けた
                                   └─ 弱い → 落ちて戻る（また焼けた）
```

| 様子 | 見えるもの | 次へ |
| --- | --- | --- |
| 空 | 黒い穴 | 1秒で生地を流す。始めてすぐは、穴ごとに 0〜1.5秒ずらす。「とろー」 |
| 生地を流す | 生地の丸が広がる | 0.6秒で焼け始める |
| 片面が焼けていく | 生地の面に具（たこ・ねぎ・紅しょうが）。縁から色づき、泡と湯気が増える | `cook_min`〜`cook_max` 秒で焼ける。「ピカッ」 |
| 焼けた | 縁が焼け色になり、ぴょこぴょこ跳ねて湯気とキラキラ | つつくと裏返る。「くるっ」 |
| 裏返る | 縦につぶれて、焼けた丸い面が上に来る | 0.45秒で反対側が焼け始める |
| 反対側が焼けていく | きつね色の丸。湯気が増える | 焼けたら「ピカッ」 |
| 焼けた | こんがりした丸がキラキラして跳ねる | 手を入れるとつかむ。つかむと震える |
| 舟皿へ飛ぶ | 弧を描いて右上の舟皿へ | 0.9秒で舟皿に乗る。「ぽん」ときらきら |
| 落ちて戻る | 少し跳ねて穴に戻る。「ぽとっ」 | 1秒はつかめない |

| 決めごと | 理由 |
| --- | --- |
| **焦げない。** 焼けたら、つつかれるまで・持ち上げられるまでいつまでも待つ | 焦げると2歳児には失敗の画面になる |
| **まだ焼けていないのをつつくと、揺れて「じゅっ」と鳴る** | 何も起きないと「無反応」になる。裏返しはしない |
| つついたと見るのは、動きが 0.06秒続いたとき | 一瞬かすっただけではつつかない |
| 一度つついた穴は、0.7秒は反応しない | 1回のつつきで二度裏返らないように |
| **持ち上げるのは「つかんでから振り上げる」** | 下の段で振り上げた手は上の段の穴を通る。振り上げた瞬間には、どの穴のたこ焼きか分からない |

> [!NOTE]
> **下の段で振り上げた手が、上の段の穴を裏返すことはある。** 焼けた片面を
> つついたのと同じに見えるため。どうせ次にやることなので、そのままにしてある。

### つかむ・振り上げる

おさかなキャッチ！と同じ判定（`vision::Grip`）を使う。

- 穴の中で動きが 0.15秒続いたら、つかむ
- たこ焼きの左右どちらかが `swing_speed` を超えて上へ動いたら、舟皿へ飛ぶ（片手でよい）
- 振り上げが弱い、または5秒振り上げないと、落ちて戻る
- 落とすたびに、要る速さを 85% に下げる（最低で 50%）。舟皿に乗ったら元に戻す

## 画面

| もの | 中身 |
| --- | --- |
| 鏡 | カメラの映像。上は暗く、鉄板の所（画面の上から 285 画素より下）は茶色く染める。透けて自分の手が見える |
| 穴 | 3個×2段。半径 100 画素と大きく取る |
| 動いた所 | 小さな光の点。自分の指がどこにあるか見える |
| 舟皿 | 右上。乗ったたこ焼きが6つまで見える |
| お祝い | 上に「12こ やけたね！」と焼けた数、下にソース・マヨネーズ・青のり・かつお節のかかったたこ焼き |

1つも焼けなかったときも、6つ並べて同じように祝う。

ソースは角丸で描く。丸には描き手が縁を付けるので、暗いソースに明るい輪が出て、
別の食べ物に見える。

## 音

| 素材 | 長さ | 口 |
| --- | --- | --- |
| `song.wav` | 61秒 | 曲。この長さで1回が終わる |
| `pour.wav` | 0.7秒 | 効果音。生地を流す |
| `sizzle.wav` | 0.4秒 | 効果音。まだ焼けていないのをつついた |
| `ready.wav` | 0.8秒 | 効果音。焼けた |
| `flip.wav` | 0.35秒 | 効果音。裏返した |
| `grab.wav` | 0.25秒 | 効果音。つかんだ |
| `serve.wav` | 1.2秒 | 効果音。舟皿に乗った |
| `slip.wav` | 0.5秒 | 効果音。落ちた |
| `fanfare.wav` | 4.5秒 | 曲。お祝いの間 |

効果音の口は1本なので、同じ1枚で2つ起きたら、乗った > 落ちた > 裏返した >
焼けた > つかんだ > じゅっ > 流した の順で1つだけ鳴らす。ジュージュー焼ける
音は鳴らし続けられないので、曲の中に薄く混ぜてある。

素材はすべて `tools/make_sounds.py` が数式から合成したもの。録音も既存の素材も
使っていないので、そのままコミットしてある。乱数の種を固定してあるので、
何度作っても同じものになる。

```sh
uv run --with numpy python3 games/takoyaki/tools/make_sounds.py
```

| 素材 | 中身 |
| --- | --- |
| 曲 | 120BPM・ニ長調の五音音階・30小節。序奏 → A → B → A → 終わり。笛の旋律、太鼓のドン・カッ、はじく和音、B からチャッパ。焼ける音を薄く敷く |
| 効果音 | とろー（なめらかな雑音と下がる音）、じゅっ（雑音とパチッ）、ピカッ（鈴2つ）、くるっ（上がる笛の音）、ぽん（低い音ときらきら）、ぽとっ（落ちる音） |
| お祝い | 笛の「ぴーひゃら」と太鼓、最後の和音とチャッパ |

## つまみ

`config.toml` の `[games.takoyaki]`。値の意味と環境変数名はそちらに書いてある。

| キー | 既定 | |
| --- | --- | --- |
| `cook_min` / `cook_max` | 4 / 8 | 片面が焼けるまでの秒数（1〜30） |
| `threshold` | 24 | 明るさがこれだけ変わったら「動いた」とみなす（1〜255） |
| `poke_ratio` | 0.06 | 穴の中で、これだけの割合が動いたら「つついた」とみなす |
| `grab_ratio` | 0.05 | 穴の中で、これだけの割合が動いたら「つかんだ」とみなす |
| `swing_speed` | 380 | 舟皿へ飛ぶ振り上げの速さ（毎秒の画素、50〜1000） |
| `show_motion` | false | 動きの向きと、振り上げの強さの棒を画面に出す |

| 困りごと | 動かすもの |
| --- | --- |
| つついても裏返らない | `poke_ratio` を下げる |
| 触っていないのに裏返る | `threshold` か `poke_ratio` を上げる |
| 振り上げても飛ばない | `swing_speed` を下げる |
| 焼けるのを待つ間が長い / 短い | `cook_min` と `cook_max` |

## コード

| ファイル | 中身 |
| --- | --- |
| `src/play.rs` | 進行。`kit::Game` の実装と、カメラの絵から判定までを通すテスト |
| `src/plate.rs` | 6つの穴の、焼ける・裏返す・持ち上げるの移り変わり |
| `src/look.rs` | 映すもの。鉄板、たこ焼き、湯気、舟皿、お祝い、調整用の表示 |
| `src/cue.rs` | 鳴らす素材。文字列ではなく型で指す |
| `src/config.rs` | `[games.takoyaki]` の型と検査 |
| `tools/make_sounds.py` | 素材を合成する |
| `assets/` | 素材（`make_sounds.py` の出力） |

動いた所と、つかんで振り上げたかを出すのは共有クレートの `vision`
（`vision/src/flow.rs`、`vision/src/lift.rs`）。
