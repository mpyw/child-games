# games — 遊びの作り方

遊びは1つのクレートで、`games/<name>/` に置く。メニューに並び、選ばれたら
装置を借りて遊び、終われば返す。

| 遊び | 中身 |
| --- | --- |
| [`donna-iro/`](donna-iro/README.md) | どんないろがすき？ 色名を聞き取って、その色の節を歌う。マイクを使う |
| [`balloon-crash/`](balloon-crash/README.md) | ふうせんタッチ 鏡に映った自分で風船に触って割る。カメラを使う |
| [`fish-catch/`](fish-catch/README.md) | おさかなキャッチ！ 池の魚をつかみ、振り上げて釣る。カメラを使う |

## 遊びがすること・しないこと

| 遊びが決める | `home` が決める |
| --- | --- |
| 何を鳴らすか（素材の名前） | 素材の在処、読み込み、埋め込み |
| 何を映すか（図形の並び） | 画素への塗り、画面の大きさへの伸ばし |
| 聞こえたものをどう解釈するか | マイク、whisper、待つ長さ |
| 映ったものをどう解釈するか（どこが動いたか） | カメラ、縮めて左右を反転する |
| 遊びの進行と、いつ終わるか | メニュー、「もう1回」、終了 |
| つまみの型と既定値と検査 | 設定ファイルと環境変数の読み込み |

> [!IMPORTANT]
> **遊びは装置にもファイルにも触らない。** 読んでよいのは `kit` と `vision` だけ。
> 依存の向きは Cargo が見張っているので、装置の crate に手を伸ばすと
> ビルドが通らない。唯一の例外は時間で、`Instant::now` と `sleep` は使ってよい。

そのおかげで、**進行はまるごと装置なしでテストできる。** 偽の装置を
`kit::Devices` に詰めて `play` を呼べば、鳴らした素材の並びをそのまま検査できる。
長さ0を返す偽の `Player` を使えば待ち時間も消える。例は `donna-iro/src/play.rs` のテスト。

## kit — 遊びが知ってよいもの

| ファイル | 中身 |
| --- | --- |
| `kit/src/game.rs` | `Game`（メニューに並ぶもの）、`Devices`（貸す装置）、`Ended` |
| `kit/src/player.rs` | `Player`、`Sound`、`Timing`。曲を鳴らし始めて長さを受け取る。効果音を重ねる |
| `kit/src/listener.rs` | `Listener` と `Heard`。子どもの答えを1回聞き取る |
| `kit/src/camera.rs` | `Camera`。縮めて左右を反転した絵を1枚ずつ受け取る |
| `kit/src/control.rs` | `Control` と `Press`。押されたものを受け取る |
| `kit/src/screen.rs` | `Scene`、`Shape`、`Image`。描く図形（丸、角丸、三角、文字、ボタン）、後ろに敷く絵、ターミナルに出す1行 |

`Game` で実装するもの:

| メソッド | 返すもの |
| --- | --- |
| `id` | `--game` で指す名前。素材の在処 `games/<id>/assets/` もこれで決まる |
| `title` | メニューに出す題 |
| `glyphs` | 題のほかに画面に出す字（点数の数字など）。無ければ書かなくてよい |
| `sounds` | 鳴らしうる素材の名前の全部。`home` が起動時に揃っているかを確かめる |
| `icon` | メニューの札に描く絵。渡された `area` の中に収める |
| `backdrop` | 「もう1回」の画面で後ろに敷く絵 |
| `play` | ひと続き遊ぶ。「もう1回」は訊かずに返る |

画面は 1280×720 のキャンバス（`kit::WIDTH` / `kit::HEIGHT`）に図形を並べるだけ。
描き手は丸と角丸と三角と文字を塗るだけで、何の遊びかを知らない。後ろに1枚だけ絵
（`Scene::image`）を敷ける。カメラの鏡像をそのまま渡せる。

### 装置の使い方

| 装置 | 決まり |
| --- | --- |
| `Player` | 口は2本。`begin` は曲で、前の曲を置き換える。`effect` は効果音で、曲を止めずに重ね、前の効果音を置き換える。`silence` は両方止める |
| `Listener` | 1回聞いて返る。待つ長さは `home` が決める |
| `Camera` | `frame` は次の1枚まで待つので、1周の速さはカメラで決まる。**使った遊びは、どこで抜けても `rest` を呼ぶ**（ランプが消える） |
| `Control` | `poll` は待たない。`wait` は来るまで待つ。`stop_requested` は「戻る」だけを見る |

> [!IMPORTANT]
> **カメラの絵は画面に出す以外に使わない。** 保存も送信もしない。子どもが映るため。

## vision — 遊びが共有する計算

カメラの絵から、どこが・どちらへ動いたかを出す。**純粋な計算だけを置く。**
遊びは他の遊びを読めず、`kit` には口しか置かないので、カメラで遊ぶものが
共有する処理はここに集める。

| 型 | 出すもの | 升目 | 使う遊び |
| --- | --- | --- | --- |
| `Motion` / `Moved` | 前の絵から明るさが変わった升目 | 80×45（キャンバスで 16 画素） | ふうせんタッチ |
| `Flow` / `Flowed` | 升目ごとの動いた向きと速さ。範囲ごとのまとめ（`Region`） | 160×90（8 画素） | おさかなキャッチ！ |

どちらも手の形は見ない。全体の半分より広く動いた絵は、照明や露出の変化として
捨てる。`vision::sample` にテスト用の絵（灰色、白い丸）があり、遊びのテストからも使える。

## どの遊びも守ること

### 無反応にしない

これが最優先。2歳児は間違ったものが流れても大して気にしない。しかし、声を
出したのに何も起きないと一気に興味を失う。

**失敗モードを「無反応」ではなく「違う答え」に倒す。** 聞き取れても解釈できなかった
ときも、何も言わなかったときも、必ず何かを鳴らす。カメラで触る遊びなら、触ったら
必ずどれかが反応するように当たり判定を甘く取る。

**時間切れや失敗の画面を作らない。** 2歳児は制限時間を理解できない。区切りが
要るなら曲の長さで決め、終わりは必ずお祝いにする。

> [!WARNING]
> **倒した先で遊びが終わってはいけない。** 聞き取れなかったときの
> フォールバックが「おしまい」の答えに当たると、事故でゲームが終わる。
> 型でそこに倒れないようにしておく。

### 終わるかどうかは遊びの外で決まる

| 状況 | 返すもの | 次に起きること |
| --- | --- | --- |
| 遊び終えた（曲が終わった、答えが「おしまい」だった） | `Ended::Finished` | `home` が「もう1回」を訊く |
| 途中で「戻る」を押された | `Ended::Finished` | 同上 |
| 入力そのものが絶えた（`Heard::Closed` / `Control` が `None`） | `Ended::Closed` | 畳む |

「もう1回」の待ちだけは、**無反応を「終わり」と読む。** 遊びのループの外なので、
黙っていることは続ける意思が無いことと同じ。ここでランダムに倒すと永久に終われない。
これは `home` の仕事なので、遊びの側では訊かずに返る。

### 操作は声で受けない

選ぶ・続ける・やめるは `Control`（押されたもの）で受け、子どもの答えは
`Listener` で受ける。系統を混ぜない。

- 歓声や物音で勝手に再開してしまう
- 続けるかを決めるのは親の仕事
- 混ぜると、答えのフォールバックが操作に化ける

遊びの途中で見てよいのは「戻る」だけ。**十字キーと決定は無視する。**
押し間違いで歌を切らないため。歌の途中で「戻る」を拾うには、待ちを細かく
刻んで `Control::poll` を見る。`Player::begin` は待たずに長さだけ返す。

### 応答の窓は「音が鳴り止んだ時点」で開く

`Player::begin` が返す `Timing` には、全長（`total`）と、鳴り止むまで（`audible`）がある。
問いかけの末尾に答えの枠として無音を入れておけば、`audible` で窓を開けられる。
鳴らし切ってから聞き始めると手遅れになる。

無音の長さは素材から測るので、音源を差し替えても追従する。

## 素材

素材は遊びごとに `games/<name>/assets/` に置く。WAV で、ファイル名は
`<素材の名前>.wav`。

| 在処 | 使われるとき |
| --- | --- |
| `games/<name>/assets/` | 全部揃っていればこちら |
| `games/<name>/assets/reference/` | 本番が欠けていて、こちらが全部揃っていれば。確認用の合成音などを置く |

**本番を置いた時点で、何もしなくてもそちらに切り替わる。** どちらも欠けて
いれば、起動時に足りないものを全部並べて止まる。遊んでいる最中には落ちない。
`reference/` が無い遊びには、この仕掛けは見えない。

素材の権利で置き方を選ぶ。

| 素材 | 置き方 |
| --- | --- |
| フリー | `games/<name>/assets/` にそのままコミットする |
| 著作物を含む | private サブモジュールにして `games/<name>/assets/` にマウントする |

> [!CAUTION]
> **著作物を含むサブモジュールは private のまま運用すること。** private で
> あれば公衆送信にあたらない。本体を public にする場合も、サブモジュールは
> private に留める。`.gitmodules` に URL は載るが、中身は保護される。

## つまみ

遊びのつまみは `config.toml` の `[games.<name>]` に置く。節の名前は遊びの
名前の `-` を `_` にしたもの。環境変数の名前に `-` は使えないため。

- **型と既定値と検査は遊びのクレートに置く**（例: `donna_iro::Config`）。
- **読み込むのは `home`。** 遊びはファイルも環境変数も知らない。
- 検査は起動時に走らせる。遊んでいる最中に気づくのが一番まずい。

**待つ長さなど、聞き取りのつまみは遊びごとに持たない。** `listen.*` は録音の
下拵えと組みで検査してあるので、遊びが変えるとその検査が効かなくなる。

## 遊びを足す

| 場所 | すること |
| --- | --- |
| `games/<name>/` | クレートを作り、`kit::Game` を実装する。依存は `kit`、`vision`、純粋な crate だけ |
| `games/<name>/README.md` | 進行・判定・素材を書く。[`donna-iro/README.md`](donna-iro/README.md) が手本 |
| `games/<name>/assets/` | 素材を置く。上の「素材」を見ること |
| `Cargo.toml`（ルート） | `[workspace.dependencies]` に足す。`members` は `games/*` なので書かなくてよい |
| `home/Cargo.toml` | `[dependencies]` に足す |
| `home/src/main.rs` | `catalog` に足す。並べた順にメニューに出る。`--help` の遊びの一覧はここから作られる |
| `home/src/config.rs` | `Games` に節を足す（つまみがあれば） |
| `config.toml` | `[games.<name>]` の節を、コメントと環境変数名つきで足す |
| `home/src/io/audio/assets.rs` | 埋め込みの表 `FILES` に1つ、表への載せ忘れを見る const の検査に1行足す |
| `home/fonts/` | 題と `glyphs` の字を足してサブセットし直す。手順は [`home/fonts/README.md`](../home/fonts/README.md) |
| `README.md`（ルート）とこの README | 遊びの表に1行足す |

配布のスクリプト（`build-pi.sh`、`bundle-mac.sh`、`check.sh`）は
`games/*/assets/` を全部見るので、直さなくてよい。

> [!WARNING]
> **whisper の復号の上限は色当ての語彙に合わせて詰めてある**（`max_tokens` 5）。
> かな5文字より長い答えを聞く遊びでは、答えが途中で切れる。
> 詳しくは [`home/README.md`](../home/README.md#その他の速度設定)。

題や `glyphs` の字がフォントに無ければ `home` のテスト（`every_label_on_screen_is_in_the_font`）が
落ちる。足したら `tools/check.sh` を通すこと。
